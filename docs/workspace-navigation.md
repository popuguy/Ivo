# Split workspaces and navigation

Implemented 15 November 2026 after Paul prioritized workspace/navigation foundations. Pane placement, shared chrome and the broader visual structure remain provisional for his later UI direction. This is original Ivo implementation informed by the retained Obsidian reference; no new native Obsidian trace or full workspace parity is claimed.

## Working behavior

- **Split Right / Split Down** are in the document options, tab context menu and native Window menu. Split the current document, reading view, graph, library or empty tab. A document split starts with the same camera and editing state, then has an independent view. Nested layouts support up to eight panes.
- Drag the divider to resize without rebuilding either editor. Escape, pointer cancellation and window focus loss restore its original ratio. Focused dividers accept the appropriate arrow keys; Shift makes a larger step, Home resets to half, and End moves to 90 percent. These are explicit Ivo controls, not measured native Illustrator behavior.
- Each pane has its own tab bar. Drag a tab between panes, including its history, pin and view state. Moving the final tab collapses its empty pane. **Merge Pane** retains all tabs in the neighboring group. Closing a tab never deletes its document; reopening uses its old group when that group still exists.
- Command/Ctrl-click or middle-click a document/link to open another tab. **Command/Ctrl+Option/Alt-click** opens it to the right. The quick switcher accepts the same Enter modifiers. **Command/Ctrl-click the reading/editing icon** opens the opposite view on the right while retaining the current view. **Command/Ctrl-Shift-N** creates and selects the title of a new note to the right.
- **Command/Ctrl-[ / ]**, the shared Back/Forward controls and native Window menu navigate the active tab's own history. Document, graph and library visits retain view state; a new route clears the forward branch. Camera restoration is tied to the particular visit, including repeated visits to the same document.
- **F6 / Shift-F6** and the native menu cycle panes. Ctrl-Tab cycles tabs within the active pane. Clicking or scrolling a pane activates it; the shared title, history buttons and application commands follow that pane.
- At window widths of 760px or less, the active pane fills the workspace. The Pane control cycles the saved panes. The split tree is retained for a wider window. Narrow document panes hide the docked inspector without reserving an empty column; Properties remains available as an overlay.

## Ownership and durable view state

`src/domain/workspace/state.js` owns a canonical tab list, pane groups, a binary split tree and per-tab navigation stacks. `src/features/workspace/layout.js` retains pane DOM while changing the layout. The application keeps one editor/graph controller per visible tab (including stacked groups) rather than recreating its neighbors for a navigation, tab-order or source change. Each visible view has its own compact header.

Two views of a document use the same canonical source and per-document undo history. Only the active pane may write text. Deactivation commits its current transaction and retains a source-selection bookmark; passive views display updates without receiving keyboard/paste commands or writing stale DOM back. Returning by keyboard restores the live bookmark. IME composition delays pane switching until the original source commits. Late blur/input events from inactive sources are rejected. Each asynchronous media import remains bound to the document/controller that accepted it, even after another pane becomes active. Structural transitions, including cross-pane tab transfers, flush pending operations before destroying a controller.

An open graph follows canonical link changes and undo while a neighboring editor retains its live DOM. Graph view snapshots store world center and scale, including through resize and Back/Forward. Topology changes currently recreate that graph controller while preserving its camera; incremental topology/large-collection work remains a separate backlog item. Depth/tag/filter controls remain shared workspace preferences; linked local graphs retain their own local scope.

The native folder manifest remains schema1; documents remain canvas4/archive5 and browser storage version4. Optional groups, layout and navigation fields extend existing `workspace:1` view metadata. Old flat workspaces upgrade automatically. Normalization repairs malformed/missing references without dropping valid tabs, restricts the tree to eight groups and tabs to 100, and stores no document text, media or undo snapshots. Live history keeps 40 entries per direction; persisted history keeps at most 20 per direction and 128 entries overall. Selection IDs and total metadata are bounded below the native 250KB envelope. Old history and selections are trimmed first; open tabs are retained. Exact DOM/caret bookmarks remain in memory, not in the vault metadata. A process restart restores the active editor/frame and cameras, rather than an arbitrary exact character selection.

Older builds do not understand split metadata and may flatten it if they save the workspace. Authored document formats are unchanged. The previous dated development build is preserved separately.

## Verification and remaining work

Seven new pure model tests cover splitting, independent navigation visits, close/merge/move, legacy repair, graph cameras, source exclusion and maximal metadata bounds. The full unit suite has **133 passing tests**.

`npm run test:navigation` runs the actual application in an isolated active Electron window with generated documents and its own reload store. It covers nested splits, retained neighbor/source DOM, shared undo/redo, input/paste ownership, rejected late passive events, IME deferral, keyboard selection restoration, delayed media ownership, independent and historical cameras, pointer/keyboard/canceled dividers, cross-pane tab transfer, modifier opening, modified view toggling, quick switching, immediate right-hand creation, narrow layouts and layout/source/media reopening. Its graph-plus-live-note screenshot was visually inspected. One fixture correction explicitly reselected the original editing tab after merging a newly created reading view; a merge correctly retains the selected moved tab.

The actual desktop main/preload/IPC fixture additionally invokes the native Split Down menu and renderer split/merge commands and reopens a real file-backed split workspace. The Swift Foundation byte adapter round-trips nested groups, navigation, pins and graph cameras. Existing text, text flows, panels, templates, selection, scene, viewport, sharp rendering, graph, storage, PDF and multi-vault regressions pass. Private logs and build ledgers are under parent `work/workspace-navigation/`.

The later [workspace shell](workspace-shell.md) extension delivers the compact reference shell, native document/tab menus, logical library actions and tear-off into real native windows. It replaces this increment's shared topbar with retained pane-local headers. Named layouts and spatial focus are delivered in [workspace-layouts.md](workspace-layouts.md). Independent contextual panels, linked/stacked views and existing-window drops are delivered in [workspace views](workspace-views.md). Native drag animation/complete modifier parity and deeper recovery remain queued. Physical iPhone/iPad, touch/Pencil, real-device IME/accessibility and frame pacing remain unverified. Authored document formats remain unchanged.
