# Design direction

Ivo should make a personal collection worth looking at and returning to. Its authored documents are the visual center. The graph is an equally real route through the collection, not an optional decorative overview.

## Reference interpretation

The supplied magazine spread offers a composition grammar: generous white space, a narrow editorial column, asymmetric photography, very small running heads, restrained captions, and one image with much greater scale than its neighbors. The prototype translates those principles into editable blocks. It does not reproduce the article, photographs, or advertising from the screenshot.

The first visual system uses warm gray navigation, white pages, dark ink, quiet rules, and a restrained blue for relationships. Georgia provides a book-like serif; the system sans stack supplies a compact editorial register. These are available system fonts, not a final commissioned type system. Academic influence enters through measure, hierarchy, captions, and room for later mathematical typography.

## Interaction contract

Reading and editing share a page. Editing exposes an explicit grid, block handles, and an inspector. Page layout and semantic connections are separate: moving an image never changes the document's graph relationships.

Each placement owns its geometry, crop, caption, and alt text. The original media remains an asset. Text supports paragraphs, emphasis, lists, simple headings, quotes, and internal links. A fixed composition is valuable on desktop; a phone reading view reflows blocks in top-to-bottom, then left-to-right order.

The first edition prioritizes authoring over a broad settings panel. It deliberately excludes themes, plugin APIs, publishing features, collaboration, and arbitrary PDF modification. These should not interrupt the central loop: collect → compose → connect → return.

## Visual review criteria

1. An ordinary document should feel composed before its author makes detailed adjustments.
2. Images must have meaningful scale, controlled crops, and calm captions.
3. Metadata should remain legible without competing with content.
4. Editing controls should appear at the point of action; reading should reveal the document.
5. A graph must remain understandable and navigable, with a keyboard-accessible document list alongside it.
6. Small screens need readable text and complete access to controls. A fixed grid may scroll in editing mode, but normal reading must not require sideways scrolling.

This is the first direction to evaluate with real material, not a claim that Ivo's visual identity is finished. Next design work should use Paul's actual research and image collections, then tune typefaces, measures, image placement presets, and motion on desktop and phone.
