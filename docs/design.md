# Product direction

Ivo is a linked-document application for Mac, iPhone and iPad. A note may be mostly long-form text, a carefully composed set of pages, scanned material with positional text, or a combination. The interactive knowledge graph remains mandatory.

The workspace takes Obsidian’s compact document navigation as its baseline. The document view uses Illustrator/InDesign-informed object selection, precise transforms, text frames, masks and page composition. It must support variable-size pages, smooth pan/zoom and original-resolution media without tying authored geometry to a grid or a blog/article template.

Current foundations include polygon objects and direct point editing, whole-object/multi-selection, masks, fractional transforms, snapping, Option-drag copying, canonical text flowing across linked pages, local history, tabs/splits/windows and Mac PDF sharing. The [backlog](backlog.md) distinguishes those foundations from measured native parity and remaining extensions.

Future requirements include richer curves/drawing, text/style breadth, scanned notes with selectable positional OCR, rectangle-to-page/region links, cloud saving/synchronization with Google Drive first, and polished cross-device editing. Original assets and source text must remain recoverable. PDF-within-PDF composition is canceled; ordinary document PDF export remains required.

The visual finish should suit fashion work: careful spacing, typography and color, pale gray application chrome, compact contextual panels and professional language. Keep document content separate from application styling. Avoid promotional prose, decorative imposed page headings, growing page-depth controls and tutorial text that occupies the working canvas. The final visual revamp remains a separate design pass.

The [architecture](architecture.md) keeps these requirements independent of the current UI. [Interface direction](interface-direction.md) records interaction constraints; [current state](development/STATE.md) and [verification](verification.md) record implementation reality.
