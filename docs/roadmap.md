# Roadmap

[backlog.md](backlog.md) is the single current feature list, with stable item IDs, status, acceptance and reference gaps. [architecture.md](architecture.md) maps those features to code owners. [development/STATE.md](development/STATE.md) records the current build and immediate engineering state.

Historical planning and verification journals are preserved in the private architecture-refactor checkpoint. They are evidence of earlier work, not a second set of current requirements.
