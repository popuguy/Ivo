# Ivo implementation backlog

Updated 18 November 2026. This is the ordered working list for Paul's requested features. New review notes enter here; they do not require an immediate detour or a complete design document. Build a usable increment and verify it on isolated data. Paul has explicitly authorized continuing through this list without waiting for a review after every step; his next large check-in comes after the backlog work. The application remains a linked-document editor for Mac, iPhone and iPad, with professional composition and a mandatory interactive knowledge graph.

Status meanings: **Foundation** works in a bounded first implementation; **Next** is the next dependency-ordered work; **Queued** is requested but not yet started; **Reference needed** identifies behavior that must be established before claiming fidelity. “Foundation” never means full Illustrator/Obsidian parity.

**Current priority: implement the expanded text/publishing scope in dependency order.** The [publishing foundation](publishing-foundation.md) adds validated styles, highlighting, frame columns/insets, reusable parent pages, layers, vault fonts and closable/rearrangeable panels, while retaining the existing text-input/viewport model. The full InDesign composer/editorial feature set and exact UI/gesture parity remain open. Word import is deferred; AI features and the Adobe online font service are excluded by the 18 November instruction.

The [text parity programme](indesign/text-parity-programme.md) now accounts for all 66 included capability IDs and their acceptance gates. The current [text-interaction milestone](text-interaction-core.md) delivers linked-frame range selection/painting, Unicode/paragraph navigation, native formatting ownership and the reported Command-I/save/reopen regression coverage. [First-baseline and frame alignment](frame-composition.md) adds real measured placement with an opt-in archive 7 / canvas 6 gate. Paragraph composition, richer structures and editorial tools remain ordered work; visible controls are not treated as completed engines.

Installed font discovery and automatic vault font packaging are delivered for the desktop/shared Apple bridge, with CMU Serif as the new-text default. See [font portability](font-portability.md). Existing note typography is preserved; unsupported/oversized fonts, direct collection-file imports, glyph-fallback capture and physical iPhone/iPad verification remain scoped boundaries.

## Delivered: object clipboard and shared text-style correction

Native object copy/cut/paste now preserves selected frames, masks/children, rich source, styles, resource bytes and independent copied flows with undo/redo. Clipboard resources persist before objects are inserted; failed or stale operations preserve authored content. Inactive display and dragging consume the same flow-owned typography as editing and PDF, preventing old per-frame defaults from reviving italic/bold/size settings. See [text-flow.md](text-flow.md) and [verification](verification.md). Cross-frame selection/composition and full InDesign text-engine parity remain in the existing publishing scope.

It is not complete InDesign parity. The detailed remaining work is ordered in that document; older rows below describe the narrower prior foundation and remain historical acceptance context.

## Progress discipline

Continue without a per-increment review stop. For each increment: link its tests/reference evidence and material limits, update this list, update the current development state, and provide a reviewable app build. Preserve existing documents and keep native tests in separate atlases/profiles. A stronger native study or a new review may change the order; adding an observation is never “jumping the gun.”
