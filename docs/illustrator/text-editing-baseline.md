# Illustrator text baseline for Ivo

6 November 2026. Primary Adobe documentation and the installed scripting declarations guide the [text editor](../text-editor.md). Raw source snapshots/hashes and the 18-sequence acceptance matrix remain private in parent `work/text-editor/reference/`.

- Whole type-object selection and a selected character range have different formatting scopes. Double-click activates Type; only the selected portion should receive a range style. [Adobe Edit fonts](https://helpx.adobe.com/illustrator/desktop/design-with-text/fonts-and-scripts/edit-fonts.html).
- Escape exits Type and automatically selects the text object. [Adobe title-design tutorial](https://helpx.adobe.com/si/illustrator/how-to/title-design.html). The previously cited release-note text is absent from the current page; do not continue treating that page as fresh support.
- Mac Command-Left/Right moves by word and Command-Up/Down by paragraph; Shift extends. Command-Shift-B/I/U formats text and Command-Shift-L/R/C aligns paragraphs; Shift-Return is a soft return. These differ from some browser defaults. [Adobe shortcuts](https://helpx.adobe.com/illustrator/using/default-keyboard-shortcuts.html).
- Leading is a character attribute; the largest value on a line governs that line. Default automatic leading is 120%. Tracking/kerning use thousandths of an em; manual kerning is an insertion-point/pair operation, distinct from range tracking. [Adobe spacing](https://helpx.adobe.com/illustrator/desktop/design-with-text/edit-format-text/adjust-line-and-character-spacing.html), [detailed reference](https://helpx.adobe.com/illustrator/using/line-character-spacing.html).
- Paragraph controls include alignment, indents and before/after spacing. Character controls include family/style/size/leading/tracking/kerning/scales/baseline shift. [Character panel](https://helpx.adobe.com/illustrator/desktop/design-with-text/edit-format-text/character-panel-overview.html), [Paragraph panel](https://helpx.adobe.com/illustrator/desktop/design-with-text/edit-format-text/paragraph-panel-overview.html).
- Undo/Redo traverse editing history; new work removes the later redo branch. Current sources do not specify a typed-character timeout or exact caret restoration. Older History examples include selection among their states, so Ivo's pure-selection-without-history policy is not asserted as universal native behavior. [Undo guide](https://helpx.adobe.com/illustrator/desktop/get-started/learn-the-basics/undo-edits-and-manage-design-history.html), [History guide](https://helpx.adobe.com/illustrator/using/recovery-undo-automation.html).

The shipped `Adobe Illustrator.sdef`, SHA-256 `ca752fed3129e592670b7a2cb16393cb89acdf89e65f56422d0308e0e95afaa9`, declares separate text-frame collections, text ranges and insertion points, character/paragraph styles and undo transactions. Declarations establish available concepts, not execution timing. Earlier [native text-control evidence](text-controls.md) remains the measured area/point conversion and scaling baseline.

A newly prepared fixture was invoked through File → Scripts, but Illustrator returned **error 1200/MRAP** in its creation statement. Only an empty owned document was produced, then closed after acknowledging the error. No new native word/paragraph/format/undo measurement is claimed. Primary documentation supports the implemented scope/shortcuts; exact click-away transitions, grouping, focus restoration, physical IME/Unicode/RTL and mixed-run metrics remain controlled-native acceptance work. Further unrelated disassembly would not prove those dynamic states.
