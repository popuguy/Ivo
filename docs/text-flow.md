# Text flowing across pages

A long document can contain one canonical rich-text source threaded through ordered area frames across pages. Current names are `document.textFlows` and `frame.textFlowId`. `domain/documents/text-flows.js` owns threading, automatic continuation, safe generated-page removal and independent copies. The [format decoder](data-format.md) preserves earlier saved documents.

`rendering/text/flow-layout.js` derives fragments using native browser layout, retained paragraph/list context and grapheme-aware boundaries. Source HTML is authoritative; fragments are disposable. Linked text is edited directly in its page frames. A single retained canonical input is projected over the active physical column, using the same camera and typography as the page. Earlier source remains in that input but is hidden from this physical column; view-only wrappers are removed before serialization. Other frames retain their derived previews. The old bottom **Document text** pane and divider have been removed. Formatting, text, geometry and structural changes share document undo. Frame geometry remains independently editable. Overset text remains in the source.

Automatic continuation copies the frame/page context as needed. Empty generated pages are removed only under explicit ownership/policy checks; authored objects must not disappear. Page order/transfer, masks, duplicated frames and templates retain stable references. Export composes a frozen snapshot, so pagination during PDF sharing does not mutate the open document.

Foundation regressions cover Unicode, lists, blank paragraphs, shared-source identity, masks, automatic pages, copying/templates, undo and persistence. `npm run test:text-flows` runs layout and application fixtures. Regressions also cover on-page continuation positioning, copy across hidden prefixes, selected-word feature feedback and repeated cross-page font-size edits. Cross-frame selections remain anchored at their first physical column to preserve their native range. Painting selection highlights across every inactive frame, pointer-drag selection spanning frames, complete native keyboard behavior across unequal columns, primary frames, advanced composition and physical iOS input validation remain backlog work. These foundations do not establish full InDesign equivalence.
