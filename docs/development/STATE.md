# Current development state

Updated 19 November 2026. This file describes current contracts; the [verification record](../verification.md) retains milestone history, test counts and review builds. The [backlog](../backlog.md) owns unfinished work.

Ivo is a linked-document editor for Mac, iPhone and iPad: precise, independently sized pages, rich text and positioned objects, an interactive knowledge graph, and portable vaults. The interface uses Geist, a pale neutral palette and professional document language. New documents use Minion Pro Regular at 12 pt with 120% automatic leading and zero paragraph spacing. CMU Serif is the offline fallback when the preferred face is unavailable. Preserve the smooth Illustrator-like frame movement and camera while extending the InDesign-based text system. Google Drive/other cloud replicas, physical mobile qualification and scans/OCR remain programme work.

The [publishing panels](../publishing-foundation.md#desktop-panels) use the InDesign Light palette. A single shape or graphic exposes Text Wrap in Properties. Window → Text Wrap opens the dedicated panel for other selections or new-object defaults. Properties → Character → More Options contains the horizontal and vertical character scales.

A signed iPhone build opens a local vault on first launch. The [iPhone startup check](../verification.md#iphone-startup-and-local-storage) covers the native bridge and a simulator document round trip. Physical typing, touch editing and iPad testing remain open.

## Text composition and current progress

The [full text-parity programme](../indesign/text-parity-programme.md) still contains the same 66 included capabilities. The [overall engineering estimate](../indesign/progress.md) is **~40%**, not certified reference/device parity. Include its small progress bar after each completed milestone. Controls, stored values and browser appearance do not by themselves complete an engine capability. AI/online Adobe font features are excluded; the remaining engine, structure, editorial, publication and device scope is substantial.

Native composition is an explicit **per-flow preview choice**. Existing notes retain their chosen composer; reads never opt a document in or rewrite its source. A canonical HTML flow owns text, typed style references and frame order. Derived fragments, native attributed strings, glyph paths, carets, break plans, tokens, PDF bytes and diagnostics are disposable.

The integrated native path now includes:

- [On-page native editing](../native-composition-editor.md): exact-font vectors, one retained canonical input, source/caret maps, cross-frame/page selection, typing, undo, automatic continuations and selectable PDF.
- [Paragraph policy](../native-paragraph-layout.md), [incremental reuse](../incremental-paragraph-reflow.md) and [unequal-frame scheduling](../native-flow-scheduling.md): alignment/justification endings, indents, paragraph spacing, ordinary indented tabs, line-specific metrics and first baselines. One owned placement plan drives ink/input/export. Preparation/search yield bounded work and geometry-only edits reuse font measurements.
- [Native object wrapping](../native-object-wrap.md): Box/Shape/Jump/Next, same-baseline fragments treated as one navigation row, transformed/clipped object exclusions and owned empty-page continuation. Current admission requires uniform metrics within each paragraph, Top exclusion columns, no tabs/centered wrapping and no advanced character transforms/features. The shared interval sweep accelerates both composers and fixes empty contour/inverse interiors.
- [Native character shaping](../native-character-shaping.md): signed baseline-shift ink, horizontal/vertical character scaling and exact-face `dlig/smcp/onum/tnum/zero/frac/ordn/salt`. Untransformed struts own line spacing. Source-range highlights/decorations/links follow native carets even when glyph runs merge. Missing features reject without synthetic font substitution.
- [Native keeps](../native-paragraph-keeps.md): whole paragraphs, one to five following lines and keep with previous, section starts by column/frame/page and parity, unequal-width whole/tail recomposition, local impossible-keep relaxation, derived violations and actual/future column ownership. Minimum opening and closing line counts work across columns, including unequal frames and local relaxation. Counts remain dormant until explicitly enabled. Chains, a following kept paragraph and keeps around supported native object exclusions now share the physical-row scheduler. Every probe/retry/cache hit consumes bounded work.
- [Native word spacing](../native-word-spacing.md): atomic minimum/desired/maximum paragraph preferences, actual font-space capacities, soft-bound full justification and condensed final lines. One measured plan owns native ink, source carets and PDF; space-advance prefix measurements preserve original tracking/ligature carets. Properties, named styles and full-paragraph rich paste share source/history and capability guards. Initial scope is simple LTR ordinary spaces without wraps, special spaces or negative tracking.
- [PDF source encoding](../native-pdf-encoding.md): a conservative stage improves eligible native ToUnicode maps from their existing ActualText without changing glyphs/paint/font bytes. Conflicting literal/ASCII ligatures retain original output with diagnostics; arbitrary imported PDFs are outside this route.

Native protocols 2/3/4/5 are internal transport versions, not persisted document versions. Default runs retain earlier protocol identity; planned frame placement uses 3, advanced characters use 4, and explicit paragraph word spacing uses 5. The shared Apple source is included by the iOS project, but Mac headless checks do not qualify iPhone/iPad or physical IME behavior.

The [desktop responsiveness checks](../verification.md#desktop-editing-responsiveness--19-november-2026) measure lock and glyph feedback in the working app. Layers update affected controls directly. The native editor retains matching rows and updates changed vector ink in place. Workspace styles depend on an explicit mount state so caret and glyph changes stay local. Physical input, IME and mobile timing remain to be qualified.

Next composition dependencies: authored letter/glyph justification constraints and hyphenation, the full paragraph objective, mixed-metric/advanced native wrap rows, minimum first/last lines of split paragraphs, grids, custom/decimal/right-indent tabs and leaders, fallback capture and variable/language/complex-script/CJK shaping. Then complete tables/lists, anchored/typed content, paths, notes/fields, editorial/publication systems and accessible interchange. Keep the dependency order and acceptance gates in the programme; do not wait for user fixtures to deliver the features needed to make them.

## Input, objects and workspace

The [text-interaction core](../text-interaction-core.md) owns linked-flow drag ranges, direction/affinity, Unicode/paragraph navigation, double-click word/paragraph behavior, explicit regular/italic overrides and native command scope. Text is edited directly in its page frames; the old bottom Document text pane is removed. Bare-newline insertion inherits surrounding typography. Partial italics, fresh paint, save/reopen and literal leading-space paste have regressions. Source/CSS normalization must never create a phantom edit on entry or selection.

Ordinary typing, selected-range replacement, grapheme deletion, paragraph joins/splits, soft returns and literal Tab now use shared rich-text operations. Window-independent checks exercise the operation itself and desktop editor checks cover linked pages, undo and input-method commit/cancel. Word deletion, composed visual-line deletion, Mac and Windows text navigation, and ordinary list-item edits now share the same history. Native numbered/bulleted composition, nested structural edits and physical input qualification remain open.

[Stable zoom](../stable-text-zoom.md) uses an unscaled authored layout with a plain 2D camera transform; CSS layout zoom must not reflow text during pinch. Preserve focal math, immediate feedback and two-decimal display. [Native editing controls](../native-editing-controls.md) own contextual Tab, Object Arrange/Adobe bracket shortcuts, menu-owned Smart Guides and the narrow page/zoom-only status strip. Browser-style UI traversal/selectable labels are suppressed while document selection, accessible field entry and native input remain available. Physical pressure/Look Up, menus, clipboard and device behavior have separate qualification gates.

The [publishing foundation](../publishing-foundation.md) supplies sparse paragraph/character styles, highlights, frame columns/insets, shared parent definitions, layers, panel groups and contextual controls. Properties reflect actual/mixed text values and preserve selection. Existing smooth object/point movement, masks, snapping and Option-drag duplication remain active; [object text wrap](../object-text-wrap.md) retains clip-before-offset geometry and whole-word contour flow. Broader drawing, snapping, panel/reference fidelity and transformed pointer behavior remain backlog work.

Workspace behavior follows the Obsidian-based shell: ordinary tabs/splits/native windows, contextual document/tab actions, vault switching, quick switching with collapsed navigation, links/backlinks/local graph, folders/bookmarks/trash and quiet workspace restoration. Preserve the unified header row, native window-button corner and full no-drag hit area for sidebar controls. [UI corrections](../ui-corrections.md), [workspace views](../workspace-views.md) and [startup](../startup.md) own the evidence. Stacked tabs and named Workspaces remain paused at the user's request; old saved flags/catalogs survive for possible later restoration.

Use ordinary ESM, focused responsibility modules and injected platform/byte ports. Features do not import the application. Keep formatting/lint/import/cycle/boundary checks enabled. [Data formats](../data-format.md): publishing archive6/canvas5; first-baseline capability archive7/canvas6; explicit native composition archive8/canvas7; object wrap archive9/canvas8; explicit paragraph word spacing archive10/canvas9. Older canonical text remains archive5/canvas4 until an authored capability is added. Native manifest1 and IndexedDB4 are unchanged. No silent format migration, native-composer opt-in or vault write on read. Native flow ownership allows derived continuation changes without inventing authored history; intentional artwork/geometry/page edits release that ownership.

[Font portability](../font-portability.md) uses installed-face discovery and persist-before-reference vault font assets. Preserve exact validated font bytes, companion identity and original media. Source IDs, fractional geometry, hidden/overset text and sparse overrides survive edits/sharing. The [vault transaction architecture](../architecture.md) preserves immutable object writes, atomic manifest replacement, pending-save fences and acknowledged writer leases; device workspace state is separate from authored documents and future replicas.

The browser app is served at the exact origin `http://127.0.0.1:4173/` by `npm run dev`. Browser-local storage is separate from native vaults. An unserved test fixture is not a user-facing preview; use `npm run preview:composition` for the standalone explanation. Full native mobile SDK/device and cloud synchronization work remain unclaimed.

## Development and review policy

Keep Git active for the remainder of the project: coherent verified feature commits, configured GitHub origin synchronized, no published-history rewrites. Read [AGENTS.md](../../AGENTS.md) and [Contributing](../../CONTRIBUTING.md). Private investigation artifacts, personal vaults, credentials, generated reference artwork and release output remain outside Git. Original investigation reports stay local as requested. Licensed public reference assets/notices remain reproducible; do not publish extracted proprietary artwork/code.

Run qualified hidden/offscreen tests with native activation prohibited so the laptop remains usable. `npm run test:background` runs 17 component groups serially; it does not qualify physical focus/menu/clipboard/IME/device behavior. Give a heads-up before necessary foreground work. Never test through a personal vault or the real clipboard, change global permission settings, or launch a review app merely to show progress. Package into a fresh release folder and leave it closed. The latest package and byte-comparison evidence belong in the verification record.
