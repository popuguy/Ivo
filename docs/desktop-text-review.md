# Ivo desktop text review

The review kit contains two disposable Ivo documents. **Fitting room proof** is a short, four-frame fitting note with a numbered footnote, a cobalt swatch embedded in a sentence, and a table with one italic word. **Contour study** has one continuous text flow through twelve frames on six pages, alongside 36 masks containing high-resolution images. Open the supplied **Ivo vault** folder with Ivo’s vault switcher. Opening the kit in its own vault keeps the test files out of your personal notes.

For the side-by-side layout comparison, open **Contour study.indd** in InDesign. Keep its **Links** folder beside it. The structured fitting note is an Ivo exercise. The InDesign file matches the separate contour study. Unzip another copy of the kit whenever you want a fresh starting point.

The supplied **Fitting room proof.pdf** shows the starting layout. Look for the swatch and footnote on page 1, the table with italic “twill” on page 2, and the final paragraph on page 3. Page 4 is an empty linked frame reserved for your reflow tests.

## Try to break a specific behavior

| Area                           | Action and expected result                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Leading and new paragraphs** | In a disposable paragraph mix small and large type. Undo the size change or return the same characters to their original size. Check the baseline before and after. With automatic leading, a remaining large character can legitimately make its line taller. A subsequent ordinary paragraph should return to its regular spacing.                                                                  |
| **Keyboard navigation**        | Try ⌘Delete in the middle of a line, Option–arrow by word, Shift with the arrow keys, and Fn–arrow at a line or document boundary. ⌘Delete removes the preceding word. Extending a selection backwards should keep its fixed end. Repeat around “Αθήνα” and “Москва”, then with an accented letter made from a letter and a combining accent.                                                         |

Undo only the paste, then redo and reopen. Look for the leading space, independently selectable artwork, preserved formatting and exactly one history step for the paste.                                                                 |
| **Style precedence**           | Define a paragraph style with a nested style on the first word. Give part of another word a local color override. Insert a new word at the beginning. The nested rule should move to the new first word. The local override should stay on its original letters. Check reading view and PDF.                                                                                                          |
| **Cell formatting**            | In Finish schedule, edit “brushed twill”. Select only “twill”, toggle italic, and add text in the adjacent cell. Find the edited words, undo, and reopen. | **PDF and EPUB**               | Export Fitting room proof in both formats. In Preview, select ordinary prose near the swatch, check the table and footnote, and zoom in on the type. | **Typing under load**          | Type steadily in a later frame of Contour study, insert returns and hold Backspace. Switch documents, come back and click mid-line. Look for a late or duplicate keystroke, a jump to the beginning, stale page content, or a caret that moves before the glyph appears.                                                                                                                              |

For a layout comparison, use the same font file, point size, leading, frame width, language and zoom in both apps. A screenshot of both views with the text-frame edges visible helps distinguish a line-breaking difference from a frame-position difference. The hardest known cases are justified paragraphs through overlapping contours. Existing comparisons already show some different line and frame endings.

## Known limits worth distinguishing

- A table placed at the text caret travels as one object. If it is too tall for every frame, expect an overset warning. Enlarge a frame to recover all of its cells. To split rows across pages and repeat headers, use a continued page table. Named cell styles are local to each table.
- Footnote bodies accept plain multiline text. Document Footnote Options control numbering, appearance and splitting. Footnotes inside table cells, separate styles within one note, and numbering restarts by section remain open.
- Inline and above-line artwork are ready to test. Custom anchor offsets and rotated text-frame hosts remain outside the qualified geometry. Windows and physical iPhone/iPad input have separate qualification work.

## Sending findings

One numbered list in chat works well. Give each distinct symptom its own number. Put lost work, damaged files and typing blockers first. A batch from one session can share the build, device, document and zoom at the top.

**A short entry is enough**

> 1. Fitting room proof, around “seam allowance”, page 2. I added three lines to the note, switched to reading view and came back. I expected the number to travel with the body. I saw the number on one page and its body on the next. Happened twice in three attempts. Screenshot 1.

That is an example of a report. If a symptom is intermittent, send what you remember even if you cannot reproduce it. For visual differences, include a pair of screenshots at matching zoom if convenient. For lag or a selection jump, a short clip showing the pointer or caret is particularly helpful. For a file that opens differently after saving, a disposable copy from just before the failure and the steps to reproduce are ideal.
