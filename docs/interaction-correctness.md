# Selection, text and live zoom

Implemented 6 November 2026 from Paul's latest review. This is a bounded interaction milestone, with the rest of the requests tracked in [backlog.md](backlog.md). It builds on the existing page/object engine and save backend. It does not replace them or establish complete Illustrator text/gesture parity.

## Selection and cancellation

Selection now has an explicit set of object IDs, separate from the active text editor, page camera and current gesture. Dragging from empty workspace creates a marquee. Partial intersections are the default; E toggles enclosed-only during the drag, and Shift toggles members. Polygon paths are tested rather than automatically counting an empty corner of their bounding rectangle. Ordinary Selection promotes clipped children to their container; Direct Selection and Draw Inside retain their distinct selection scopes.

Several objects receive one common eight-handle bounding box and individual outlines. Move, axis-aligned resize, keyboard nudges, duplicate and delete operate on the selected roots as one document transaction. A selected ancestor excludes its descendants from the operation list, preserving clipping relationships and identities. Selection changes and cancelled marquees create no document-history entry. Escape restores a cancelled gesture. A released mouse reported during a later hover finalizes a pending drag without applying that hover location, guarding against native popups consuming mouse-up.

These are polygon/frame selection rules. Full native painted/path/clip hit rules, persistent groups, isolation, rotation and general affine transforms remain explicit backlog work. A multi-object scale scales selected text; independent single area-frame resizing continues to reflow text without scaling glyphs. A full native comparison of every mixed selection is still required.

## Live text and saved source

The old double-click path repainted the document and replaced the editable DOM node. That discarded the browser's caret/word selection. Ivo now enables one existing text surface and leaves repeated native double/triple clicks alone. The initial Selection-to-Type double-click places the caret at the clicked position and selects the word, including words spanning inline emphasis. Word mapping recognizes paragraph/BR boundaries. V/T and other plain letters remain text while editing. Composition events and composing Escape are guarded; this is not a substitute for physical IME/device coverage.

The first click outside an active text surface ends the edit without making another frame. Clicking another text surface enters it. Escape exits to Selection. Object handles and the conversion circle are hidden while typing. Plain editing clicks on links retain text focus; Command/Control-click keeps the explicit document-navigation path.

Saving retains inert DIV as well as P and BR paragraph structures. Previously the sanitizer unwrapped DIV, which could join lines generated by native editing or pasted content. Script/event attributes and active elements remain excluded. This adds no archive schema or typography-style change. Existing HTML, emphasis, links and original object IDs are preserved. Paragraph spacing remains the existing document style pending the larger typography pass.

Text properties can still repaint a frame and lose its live caret/selection; selected-run typography, mature transaction boundaries, threading, RTL, physical IME, accessibility and clipboard breadth are next. Link insertion is its own document transaction and can repaint the surface. This milestone must not be described as a complete Illustrator text clone.

## Menus and panel chrome

Physical undo/redo and insert-link buttons are removed from the drawing rail. Undo/redo remain in the native Edit menu and keyboard. Document linking is available in native Insert, the native right-click menu and shared document options. Selected text is wrapped with a stable document-ID link, preserving its text/emphasis. The browser fallback has an accessible keyboard-navigable context menu. Native context requests are restricted to the trusted main renderer and a fixed command set.

The Properties/Pages/Links underline navigation is replaced with compact raised tabs and a 13-pixel collapse bar. Rectangular tooltips are delegated outside document zoom, with native artwork retained. Moving between a button and its image does not cancel the tooltip timer. The micro-bar establishes a provisional reference; floating/dockable Pathfinder-like **nonmodal** panels remain UI-03. Exact native tooltip spacing, colors and timings are not claimed.

## Sharp live zoom and native gain

The page compositor used a scale transform on an already painted page. During rapid scale changes Chromium could temporarily enlarge that cached raster, producing Paul's blurry/pixelated text. `src/rendering/page-camera.js` now changes **layout zoom**, so text/SVG paint at the requested size, and uses the compositor transform only for translation. The editable nodes and document-space geometry remain unchanged. CSS no longer asks Chromium to keep the entire page as a transform-animation bitmap. This is live DOM/vector text rendering, not a new PDF/Canvas text engine.

A deeper native trace established Illustrator's ordinary update as `z_next = z * (1 + magnification)`. The version-pinned Chromium Mac pinch bridge converts that factor into DOM wheel delta with logarithms, whose inverse is `exp(-deltaY/100)`. Ivo's previous `.005` coefficient applied the square root of the delivered factor. Ctrl-wheel/pinch now uses the established `.01` inverse; Alt-wheel remains Ivo's separate convenience gesture. The status always shows two decimal places. See the [reference and caveats](illustrator/interaction-reference.md).

Native gesture initialization, stored anchor, event accumulation/coalescing, optional quantization, preferences and zoom bounds remain different or unmeasured. Touch uses the actual two-touch distance ratio. No physical trackpad or iPhone/iPad parity is claimed from synthesized component events.

## Verification and review limits

- **92 Node tests pass**, including immutable multi-object transforms, selection hierarchy/intersections, camera paint separation and versioned pinch inversion.
- `test:interaction` uses the actual editor/CSS in an isolated Electron window. It checks partial/enclosed/Shift/cancel selection, one-transaction group movement, interrupted mouse release, stable live text identity/native selection, composition Escape, cross-format word links, editing-link focus, click-away cancellation, paragraph sanitization, rail/menu changes, decimal zoom and tooltip lifetime.
- `test:scene` passes the prior page/point/mask/paste/text-conversion and mixed-page checks. `test:viewport` retains immediate camera updates, fixed zoom focus, unchanged document geometry, and zero selection-node insertions or text-overflow reads during camera-only movement with 500 objects.
- `test:render` now fences actual submitted offscreen frames with stage and geometry markers. Its first312.5% frame and settled frame at emulated2-pixel density are pixel-identical: zero changed RGBA channels. CMU regular/italic under layout zoom also matches independently sized font text exactly. Fractional geometry error is at most 0.0075 CSS pixels across tested zooms. The earlier500-object apply-plus-forced-layout p95 was about4.1ms on this host; consult the latest verification ledger for the current run. These are component measurements, not optical display latency or physical-device performance guarantees.
- Native CUA used only **Ivo Interaction Test**, `com.paulcantrell.ivo.interactiontest`, with separate atlas/profile in parent `work/selection-text-review/`. It verified a two-object marquee/common eight handles, shared move and resize with undo, entering/repeating word selection, triple paragraph selection, replacement of only the selected word, native text/session undo, click-away without another object, native right-click selected-word linking, top Insert menu, collapse/restore and two-decimal zoom. Native Enter/blank paragraphs survived quit/reopen; independent vault reads confirm the three original object positions and complete paragraph source.

Two tightly batched native automation sequences around undo/menu transitions unexpectedly moved a selected object before the intended text entry. Each was undone, and separately observed actions then passed. The released-hover guard and editing-link default-action fix address concrete unsafe paths, but the original event trace was not captured. Include rapid undo/menu-to-pointer transitions in the next controlled text matrix; do not claim exhaustive race elimination.

Native test data/app remain private. The test app was closed; the normal Ivo session, its atlas, personal Illustrator documents and global permission settings were left alone. Shared iPhone/iPad files can be built from this code, but full Xcode/device validation remains pending. Build identities and logs are retained in parent `work/selection-text-review/`.

Later verification note: see [text history and live formatting](text-editor.md) for the superseding unified undo implementation, and [verification](verification.md) for the submitted-frame rendering fixture. A RAF callback alone does not prove a screenshot contains that new paint. The current test uses explicit paint-stage and requested-geometry markers before its pixel comparisons.
